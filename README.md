## 📌 Overview

A practical tour of natural language processing in Python, from reading text files and regular expressions to text classification, sentiment analysis, topic modeling and neural text generation. Each module includes projects or assessments with solutions.

> 📚 **About this repository:** these are my study notebooks and exercise solutions from an online course. The course materials are © Pierian Data Inc. and are shared here for personal learning and reference.

## 🧭 What's inside

| # | Module | Topics |
|---|---|---|
| 00 | **Python text basics** | Working with text and PDF files, regular expressions |
| 01 | **NLP basics** | spaCy, tokenization, stemming, lemmatization, stop words, vocabulary and phrase matching |
| 02 | **Part-of-speech tagging & NER** | POS tagging, named entity recognition, visualizing with displaCy, sentence segmentation |
| 03 | **Text classification** | scikit-learn primer, feature extraction (bag of words, TF-IDF), text classification project |
| 04 | **Semantics & sentiment analysis** | Word vectors and similarity, VADER sentiment analysis, sentiment project |
| 05 | **Topic modeling** | Latent Dirichlet Allocation (LDA), Non-negative Matrix Factorization (NMF) |
| 06 | **Deep learning for NLP** | Keras basics, text generation with LSTMs, a question-answering chatbot on the bAbI dataset |
| 07 | **Bonus** | Building a corpus from files, working with stop words |
